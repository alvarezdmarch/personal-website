SIGraDi Tools

Desktop app development / Python

A Windows desktop app designed and built for the organizing committee of SIGraDi 2026 (Santiago, Chile). It brings the conference's administrative work into one window: payment receipts reconciled from OpenConf and PayPal, certificates per role with verifiable codes, webcam QR check-in at the registration desk, and safe email sending with a dry run before every send.

  • English, Spanish & Portuguese
  • Works offline
  • Invite-based server access
  • One profile per edition
